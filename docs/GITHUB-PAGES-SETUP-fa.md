# راه‌اندازی GitHub Pages برای صفحات حقوقی Karbama

این راهنما فقط پس از push شدن فایل‌های `docs/privacy-policy.html` و `docs/delete-account.html` اجرا می‌شود.

## URLهای عمومی مورد انتظار

اگر Pages از branch `main` و folder `/docs` فعال شود، URLها این خواهند بود:

- `https://ntgalaxy1.github.io/karbama34/privacy-policy.html`
- `https://ntgalaxy1.github.io/karbama34/delete-account.html`

تا وقتی Pages در repository فعال نشده و URLها در مرورگر بدون login باز نشده‌اند، این URLها را در Play Console وارد نکنید.

## فعال‌سازی

1. در GitHub repository `ntgalaxy1/karbama34`، وارد **Settings → Pages** شوید.
2. در **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کنید.
3. Branch را `main` و folder را `/docs` انتخاب کنید.
4. روی **Save** بزنید.
5. GitHub ممکن است چند دقیقه برای deploy نیاز داشته باشد. هر دو URL بالا را در پنجرهٔ ناشناس مرورگر باز کنید.
6. فقط وقتی هر دو صفحه با HTTPS و بدون login در دسترس بودند، URL Privacy Policy و URL حذف حساب را در Play Console وارد کنید.
